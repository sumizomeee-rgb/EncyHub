# Hierarchy 与 Inspector

Hierarchy 用于查看游戏运行时 Unity 节点树和组件属性，替代旧的 C# Component Monitor 工作流。

## 当前交互

- 节点按需展开，避免一次传输完整场景树。
- 选中节点后加载 GameObject 和组件详情。
- 支持按名称、路径、组件和值搜索，并可跳转到命中节点。
- 数字属性可在编辑区域滚轮增减，默认步长为 `1`，同时阻止页面滚动冲突。
- 左键短暂长按后进入拖拽；落点明确区分“同级前/后”和“成为子节点”。
- 拖动完成后局部更新并保持选中、展开和滚动定位，避免整棵树刷新。
- 中键定位会在网页显示成功/失败反馈，不触发页面自动滚动。

## 游戏内定位高亮

定位不修改目标对象上的组件。运行时在目标附近创建临时高亮对象，并在短时间后自行销毁：

- UI：根据目标自身的 RectTransform 绘制四边定位框。
- 3D：聚合目标及激活子节点的 Renderer 边界；没有 Renderer 时在 Transform 位置显示固定小包围盒。
- 临时对象继承目标的 layer，tag 固定为 `Untagged`。相机仍可能因自身 culling mask 不包含该 layer 而看不到高亮。
- 目标在高亮期间被销毁、禁用或切换场景时，清理逻辑必须安全退出。
- 高亮对象不得参与业务碰撞、射线或持久化，也不得挂载到业务对象本体。

这种方式的侵入范围只限于临时可视对象，不改变目标材质、Graphic、Renderer 或业务状态。

## 拖拽语义

拖拽命中区域应优先保证同级排序可操作：节点上、下边缘分别表示插入前后，中部才表示成为子节点。非法情况包括拖到自己、拖到自己的后代，以及目标在提交前已经失效。

运行时操作失败时保留当前树状态并显示错误，不应通过全量刷新掩盖失败。
