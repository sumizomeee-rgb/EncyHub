# Lua UI Inspector

Lua UI Inspector 用于查看运行中 Lua UI 实例、字段和值，并与 Hierarchy 互相定位。

## 实例身份

UI 名称不是唯一键。同名弹窗可以同时存在，因此列表、选中状态、缓存和协议都使用实例 UUID。排序按视觉堆栈从下到上排列，最顶层实例显示在列表最下面。

UI 销毁后必须按 UUID 清理，不能让后来创建的同名实例复用旧实例的选中状态或列表位置。

## 数据浏览

- UI 列表与字段数据分开获取。
- 复杂表结构按需展开，避免无限递归和一次性大包。
- userdata、function 等不可安全序列化的值只展示类型或摘要。
- 刷新时尽量保留选中项、展开项和滚动位置。

## 搜索

搜索支持名称、层级路径、字段和值等模式。结果排序优先考虑匹配质量、激活状态和层级深度；跳转时应展开祖先链并定位真实实例。

文本穿透只对受控类型和字段生效，并设置遍历深度、节点数量和结果数量上限，避免搜索阻塞游戏主线程。

## 与 Hierarchy 联动

从 Lua UI 跳转到场景节点时使用该实例对应的 GameObject 标识，不依赖 UI 名称。反向定位同样需要验证实例仍然存活；失效时只返回明确错误，不重置整个页面。
