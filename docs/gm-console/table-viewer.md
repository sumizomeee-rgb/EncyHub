# 配表查看器

配表查看器用于浏览游戏运行时已经加载或可访问的配置表结构与行数据。

## 能力

- 枚举表和 Schema。
- 按字段或关键字查找行。
- 分页返回数据，避免大表一次性序列化。
- 对复杂值提供受限展开和类型摘要。
- 在可用时展示加载或访问统计；统计能力不可用时不影响基础查看。

## 安全边界

- 默认只读，不通过查看器修改运行时配表。
- 查询设置最大行数、字段深度和响应大小。
- 单表读取失败只影响当前请求。
- 不把完整配表缓存永久写入仓库或浏览器。

协议和运行时实现以 `tools/gm_console/runtime_gm_client.lua` 为准，不再维护独立参考 Lua 文件。
