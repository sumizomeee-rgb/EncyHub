# 分包监控

分包监控展示游戏资源分包的静态结构与动态下载状态。

## 数据模型

数据分为两类：

- 结构：分包、资源组、大小及包含关系，首次进入或手动刷新时获取。
- 状态：未下载、准备中、下载中、暂停、完成、卸载等运行状态，按较短周期更新。

前端合并结构与状态后计算总数、完成数、下载中数量和容量统计。配置中存在但运行时索引缺失的资源必须保留并标注异常，不能静默消失。

## 性能边界

- 静态结构不随每次轮询重复发送。
- 动态刷新只传必要字段。
- 页面断开或切换客户端后取消旧订阅。
- 大列表的筛选和展开状态在前端完成。

权威游戏端实现位于 `tools/gm_console/runtime_gm_client.lua`，不再维护独立参考 Lua 副本。
