# 游戏日志

游戏日志页通过 RuntimeGM 客户端读取游戏实际日志文件，并把增量内容发送到 GM Console。

## 平台路径

- Windows Editor / Player：从运行时环境和已知日志目录解析。
- Android：使用应用 `persistentDataPath/log` 下的日志文件。
- iOS：仅在运行时能够解析并访问日志目录时启用。

路径解析失败时应返回状态消息，而不是持续重试或影响其他 GM 功能。

## 增量读取

- 只读取上次偏移之后的新内容。
- 文件轮换、截断或切换时重置偏移。
- 按日志条目边界组装多行内容。
- 单次读取设置字节和条目上限，避免大日志阻塞游戏。
- 页面取消订阅、连接断开或客户端销毁后立即停止 tail。

## 隔离原则

日志订阅属于具体游戏会话。会话标识切换时订阅状态需要迁移；多客户端之间不能串日志。缓存只用于短期补发，不作为持久化日志仓库。
